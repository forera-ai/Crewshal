## Exact incompatibility

At pinned official Codex commit `d27764b82f7118f674371e6d6e76271d9d606edb`, app-server startup requires SQLite state initialization. It calls the error-propagating `try_init` path; its separate optional-state fallback is not used. Noncorruption initialization failure returns an app-server startup error. The pool uses ordinary writable SQLite connections, up to five connections, and explicitly selects WAL before migrations. [App-server caller](https://github.com/openai/codex/blob/d27764b82f7118f674371e6d6e76271d9d606edb/codex-rs/app-server/src/lib.rs#L618), [rollout initialization](https://github.com/openai/codex/blob/d27764b82f7118f674371e6d6e76271d9d606edb/codex-rs/rollout/src/state_db.rs#L41), [SQLite pool](https://github.com/openai/codex/blob/d27764b82f7118f674371e6d6e76271d9d606edb/codex-rs/state/src/sqlite.rs#L285).

Its Unix WAL-index mapper uses `MAP_SHARED`; a denied mapping returns `SQLITE_IOERR_SHMMAP`, without falling back to heap storage for that failure. The ordinary database-file mmap fallback is a different path. [Codex dependencies](https://github.com/openai/codex/blob/d27764b82f7118f674371e6d6e76271d9d606edb/codex-rs/Cargo.toml#L477), [lockfile](https://github.com/openai/codex/blob/d27764b82f7118f674371e6d6e76271d9d606edb/codex-rs/Cargo.lock#L9376), [crate metadata](https://github.com/rusqlite/rusqlite/blob/v0.39.0/libsqlite3-sys/Cargo.toml#L1), [bundled version](https://github.com/rusqlite/rusqlite/blob/v0.39.0/libsqlite3-sys/sqlite3/sqlite3.h#L143), [Unix WAL mapping](https://github.com/sqlite/sqlite/blob/version-3.51.3/src/os_unix.c#L4914).
