## Observable behavior

[The new supervisor module](../src/crewshal/supervisor.py) captures an already admitted process. It creates no process, cgroup, unit, namespace, mount, policy, credential channel or provider request. A future qualified launcher must supply its actual retained child handle, exclusively read stdout/stderr pipes, launch timestamps and prospectively retained owned cgroup identity. No prepared native/proxy argv is run directly on the host. Historical qualification drivers are not imported or wrapped.

`OwnedCgroup.attach` is a Linux-only entry point. Its source checks the standard cgroup2 mount and recursive resource-event accounting, walks a non-root subtree without symlinks, excludes worker directory write authority and retains the exact device/inode through an owned directory descriptor. Controller reads and the single `cgroup.kill` write use that descriptor; path replacement cannot redirect the stop to a different group. The source checks the original 128 MiB/zero-swap/one-CPU/32-task worker controls and domain type. This does not establish the aggregate envelope, migration exclusions, role policies, process placement or kernel compatibility. Attachment has not run on Linux.

`capture_attached_process` uses nonblocking descriptor reads with at most 65,536 bytes retained per stream. Truncation retains an incomplete stream flag and requests an owned stop; success text cannot supply process or cgroup observations. Completion requires a reaped native child, recursively empty `cgroup.events:populated`, empty direct process inventory and actual EOF on both pipes. Root exit or an empty `cgroup.procs` list alone cannot hide descendants. Resource-refusal counters, cancellation, negative exit, changed/unreadable controls and a still-populated group after root exit prevent successful collection. Deadline accounting includes time before attachment: five seconds for worker activity, at most one second of stop observation and ten seconds of capture. These are cooperative source policies; hard enforcement remains an independently qualified launcher/watchdog obligation. No resource ceiling is relaxed.

Only the pinned owned subtree receives a stop. Failure to stop/read back leaves `tree_stopped` false. Reader/poll/cancellation exceptions attempt a best-effort owned stop and propagate; they do not manufacture a terminal receipt. Pre-capture identity/input/refusal failures leave reconciliation to the admitted launcher. The supplied process handle, clocks and cancellation callback are trusted and must be nonblocking. Their actual PID/start identity, native bytes, placement and transport/credential separation must be established by the missing launcher. An arbitrary protocol object is not a qualified process.

`collect_supervised_codex` first checks the exact lease/state versions, acknowledged attempt/handle, source/task/launch context, narrow README task/check and explicit selection. It shares the existing [collection body](../src/crewshal/integration.py) inside one coordinator-owned transaction; the public `collect_codex_attempt` wrapper still owns its own transaction. This avoids nested SQLite transactions without adding generic nested-transaction behavior. Receipt insertion, terminal collection, claims, usage, changed candidate and scope commit or roll back together. A failed SQL transaction can leave owned freeze/capture files; a retained freeze target refuses reuse. No automatic process retry occurs.

The closed `SupervisionReceipt` record preserves initial/final controls, cgroup identity, handle/PID, observation, source-bound dispatch and collection/log digests. Contradictory stop/overflow claims refuse parsing. [The durable registry](../src/crewshal/durable.py) accepts this record without changing the SQLite table schema. Successful scope evidence references its private artifact, so the existing final artifact readback rejects receipt mutation. Private receipt/raw-capture artifacts remain mode 0600 under coordinator state. Filesystem artifacts are not transactional; same-user hostile replacement and independent owner authentication remain outside the demonstrated offline boundary.

[Dispatch preparation](../src/crewshal/dispatch.py) now binds twelve package source files, including `supervisor.py`. The changed supervisor, collection and durable bytes invalidate earlier prospective configurations. Original v18 eligibility and old configuration approvals cannot transfer.
